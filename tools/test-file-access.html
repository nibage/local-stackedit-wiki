Test local file access

This standalone page checks whether Chrome or Edge permits local folder access when you open index.html by double-clicking it. No internet or external libraries are required.

Use only a disposable test folder, such as the included demo-wiki.

The browser asks for permission, creates a uniquely named temporary file, verifies writing and reading, then deletes the temporary file. It never overwrites existing files. Any cleanup failure is reported.
