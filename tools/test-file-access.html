Test lokálního přístupu – dávka 18

Tato samostatná stránka slouží k ověření, zda Chrome nebo Edge umožní aplikaci pracovat se složkami při otevření index.html dvojklikem. Nepotřebuje internet ani žádné další knihovny.

Použij pouze testovací složku, například přiloženou demo-wiki.

Po kliknutí na tlačítko prohlížeč požádá o přístup ke složce, vytvoří v ní náhodně pojmenovaný dočasný soubor, ověří zápis a čtení a soubor odstraní. Stávající soubory nepřepisuje. Pokud odstranění selže, zobrazí upozornění.
